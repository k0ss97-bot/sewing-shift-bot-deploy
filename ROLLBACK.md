# ROLLBACK

## Код

1. Остановить целевые сервисы.
2. Атомарно вернуть `/opt/sewing-web/current` на заранее зафиксированный предыдущий release path.
3. Запустить сервисы и выполнить health + бизнес-smoke.

## Данные

- Текущий кандидат добавляет SQLite-таблицы неразрушающим `CREATE TABLE IF NOT EXISTS`; старый код может их игнорировать.
- PostgreSQL reconciliation только читает WMS и не требует data rollback.
- Откат базы выполняется только при доказанной порче данных, после прямого подтверждения владельца.

## Критерий

Откат завершён только после совпадения active symlink/`COMMIT`, успешного `/health`, авторизованного бизнес-smoke и отсутствия новых дублей/отрицательных остатков.
