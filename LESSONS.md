# LESSONS

## L-001 — Стандартный unittest discovery молча пропускал namespace tests

Причина: каталог `tests/` не являлся обычным package для рекурсивного discovery. Старый runner выполнял 132 теста при 233 объявленных функциях. Исправление: явный импорт всех `test*.py`, дедупликация ID и машинный отчёт.

## L-002 — Унаследованный WMS URL опасен для тестов

PostgreSQL WMS-тесты пересоздают таблицы. Наследование production `WMS_DATABASE_URL` недопустимо. Runner теперь игнорирует его и принимает только явно тестовый URL.

## L-003 — Environment-only учебный режим нельзя безопасно эксплуатировать

Переменная окружения не показывала текущий статус пользователю и не сохраняла автора изменения. Режим перенесён в журналируемую настройку SQLite, при этом environment остаётся только bootstrap default.

## L-004 — Outbox требует регулярной сквозной сверки

Идемпотентность отдельной функции не доказывает отсутствие пропущенного или несовпадающего движения. Добавлена проверка упаковки, outbox, WMS movement, ProductKey, количества, source ID и отрицательных остатков.

## L-005 — Подтверждение уведомления не было покрыто тестом

SQL использовал несуществующий алиас `shifts` в `UPDATE critical_notifications`. Ошибка обнаружена при расширении мониторинга. Запрос исправлен на `WHERE id = ? AND status = 'open'`, добавлен тест однократного подтверждения.

## L-006 — Server units и repository units могут расходиться

На сервере найдены units, отсутствующие в текущем репозитории, включая healthcheck и transient test/sync services. Фактическое расписание всегда проверяется через systemd; удаление неизвестных units без классификации не выполняется.

## L-007 — Immutable release должен иметь commit marker

Имя release-каталога и hash-файлы позволили подтвердить `f7cae4e`, но отдельного `COMMIT` файла не было. Следующий deploy должен записывать commit marker для воспроизводимого аудита.
