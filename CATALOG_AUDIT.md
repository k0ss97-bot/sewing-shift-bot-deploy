# CATALOG AUDIT

**Дата:** 2026-08-07  
**Статус:** механизм классификации и выгрузка есть; аудит фактических production-данных ещё не выполнен.

## Требуемая выгрузка

| Поле | Источник/правило |
|---|---|
| Площадка | Ozon/Wildberries |
| Marketplace ID | внешний product/variant ID |
| Артикул | offer/vendor code; пустое — ошибка |
| Штрихкод | source barcode + alternate barcodes |
| Цвет/размер | source attributes, затем нормализация |
| Производственное изделие | exact normalized mapping или явная причина «нет связи» |
| Маршрут | найден/отсутствует |
| ProductKey | шесть полей WMS или ошибка формирования |
| Конфликт | duplicate article/barcode и список конкурирующих вариантов |
| Актуальность | active/irrelevant, без физического удаления |

## Правила приёмки

- Каждый active-вариант имеет ровно один объяснимый статус.
- Несвязанный active-вариант с найденным изделием, но без маршрута, считается ошибкой.
- Неактуальные товары переводятся в статус/ячейку «Неактуальные»; история не удаляется.
- WMS `warehouse_stock` не подменяется Ozon/WB `marketplace_stocks`.

## Фактическая матрица

Не заполнена: production-таблицы и marketplace-снимки в этом этапе не читались. Требуется read-only CSV/XLSX-выгрузка из целевой базы после публикации кандидата.
